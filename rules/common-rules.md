# 공통 규칙

Mapshot-API, Mapshot-Front 둘 다에 적용한다. 규칙이 바뀌면 이 파일을 고치고, 왜 바꿨는지는 `decisions/` 에 남긴다.

레포별 코드 규약(구조, 레이어, 상태 관리, 테스트)은 따로 둔다.

- [api-code.md](api-code.md): Mapshot-API
- [front-code.md](front-code.md): Mapshot-Front

## 1. 문서와 결정

- 기획·결정·설계 메모는 이 레포(mapshot-planning)에만 쓴다. 코드 레포에는 `CLAUDE.md`(작업 가이드)만 둔다.
- 결정을 남길 때는 버린 선택지와 이유를 같이 쓴다.
- 코드 주석에는 '왜 이렇게 했는지'를 쓴다. 긴 배경 설명이 필요하면 이 레포 문서를 가리킨다.

## 2. 브랜치·커밋·PR

- 브랜치는 `feat/<주제>` 에서 작업하고 `master` 로 PR.
- 커밋 메시지는 한국어, `feat:` / `fix:` / `style:` / `refactor:` / `docs:` 접두.
- PR 본문: 무엇을 왜 바꿨는지, 화면이 바뀌면 스크린샷, 확인한 것과 못 한 것. 상세 기획은 이 레포 링크로.

## 3. 광고(애드센스)

프론트 코드 주석(`Mapshot-Front:src/components/ads/AdSlot.vue`, `MapView.vue`)에 흩어져 있던 규칙을 모은 것.

- 광고 자동 새로고침(일정 시간마다 광고를 다시 요청하는 것)은 **애드센스 정책 위반이라 금지**다.
  애드센스에는 공식 새로고침 기능이 없고(새로고침 신고 기능은 Ad Manager 쪽에만 있다), 코드로 만들면 계정 정지 사유가 된다.
  광고는 화면에 붙을 때 한 번만 요청한다.
- 같은 `<ins>` 에 두 번 push 하면 에러가 난다. 숨겼다 보였다 하는 광고는 `v-if` 가 아니라 `v-show` 로 감싼다(재마운트 = 새 광고 요청).
- 클릭을 유도하는 버튼(예: 템플릿 제작) 바로 옆에 광고를 붙이지 않는다. 간격과 구분선을 둔다.
- 광고 슬롯을 띄울지는 첫 진입 때 창 크기로 한 번만 정한다. 창 크기가 바뀔 때마다 다시 그리지 않는다.
- 광고 자리를 늘리기보다 체류시간을 늘려 기존 자리의 노출을 늘리는 쪽을 먼저 본다.

## 4. 외부 API 와 키

- 외부 API 키가 필요한 호출은 반드시 서버를 거친다. 프론트 코드나 프론트 환경변수에 키를 넣지 않는다.
  (카카오맵 JS 키처럼 원래 브라우저용으로 발급된 키는 예외)
- 외부 호출은 실패해도 서비스 전체가 멈추지 않게 한다. 실패하면 로그를 남기고 다음 회차에 다시 시도하거나 폴백을 쓴다.
- 호출량이 정해진 API 는 서버 쪽에서 상한과 캐시를 둔다.

## 5. LLM 호출

- 기사·항목마다 한 번씩 부르지 않고, 모아서 한 번에 부른다(무료 티어 레이트리밋).
- 출력은 정해진 스키마의 JSON 으로 받는다(`responseMimeType: application/json`, 추론 토큰 끔).
- LLM 이 URL·좌표·코드 같은 식별자를 직접 만들게 하지 않는다. LLM 은 번호나 텍스트만 내고, 실제 값은 서버가 매핑한다.
  - 예: 도시뉴스 브리핑의 출처는 `sourceRefs`(입력 번호) → 서버가 URL 로 변환
  - 예: 도시소식 지도의 지역은 지명 텍스트 → 서버가 행정구역 사전으로 코드·좌표 변환
- 실패하면 서비스가 멈추지 않게 폴백이나 재시도 경로를 둔다.
- 나중에 평가할 수 있게, 의미 있는 LLM 출력은 원문을 같이 저장한다.

## 6. 외부 데이터 수집

- 수집 전에 확인한다: 이용 약관·라이선스(공공누리 유형 등), robots.txt.
- 화면에는 출처 기관과 원문 링크를 같이 보여준다.
- 언론사 기사 본문을 긁어 저장하지 않는다. 언론사 사진은 재호스팅하지 않고 링크만 건다.
- 같은 서버에 연속 요청을 몰지 않는다(요청 사이 간격을 둔다).
- 브이월드 지오코더처럼 '결과 저장 금지' 조건이 있는 API 의 결과는 DB 에 넣지 않는다.

## 7. 위치정보

- **사용자 위치정보**(사용자가 클릭한 좌표와 그로부터 나온 주소 등)는 공개 API 응답에 넣지 않는다.
- 행정구역 대표점처럼 사용자와 무관한 대략 좌표는 내려줘도 된다. 대신 화면에 '대략적인 위치'라고 밝힌다.
- 배경: `decisions/2026-11-25-location-rule-scope.md`

## 8. 데이터베이스

- H2 파일 DB, `ddl-auto: none`. 스키마 변경은 `schema.sql` 에 멱등하게(`IF NOT EXISTS`) 쓴다.
- 테이블을 더 안 쓰게 되면 `schema.sql` 에서 생성문만 빼고, 운영 DB 의 테이블은 따로 정리한다.
