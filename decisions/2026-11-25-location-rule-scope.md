# 위치정보 규칙은 '사용자 위치'에만 적용한다

> 날짜: 2026-11-25 · 영향 레포: API, Front

## 계기

도시뉴스 기획서(2026-06)에 "좌표·주소는 응답에 절대 넣지 않는다(민감정보 정책)"는 규칙이 있었다.
도시소식 지도 레이어는 보도자료를 지역 단위로 지도에 찍어야 해서 좌표가 필요했다.
규칙을 왜 만들었는지 확인해보니, 막으려던 건 사용자 위치정보였고 지명 자체를 숨길 이유는 없었다.

## 결정

- 공개 API 에 넣지 않는 것: 사용자 위치정보(사용자가 클릭한 좌표, 거기서 나온 주소, 사용자를 특정할 수 있는 위치 기록).
- 넣어도 되는 것: 행정구역(시도·시군구) 대표점처럼 사용자와 무관한 대략 좌표. 화면에 '대략적인 위치'라고 밝힌다.
- 도시뉴스 브리핑 응답은 지금처럼 지명 텍스트만 쓴다(바꿀 필요가 없어서).

## 버린 선택지

- 좌표 없이 지명만 내려주고 프론트에서 카카오 지오코딩: 마커마다 브라우저가 지오코딩을 호출하게 되고, 결과가 매번 같아 서버에서 한 번 정해두는 게 낫다.
- 브이월드 지오코더로 서버에서 좌표 계산 후 저장: '결과 저장 금지' 이용 조건 때문에 안 된다.

## 다시 볼 조건

사용자별 위치 기능(내 주변 소식 등)을 만들게 되면 그때 사용자 위치를 어떻게 다룰지 따로 정한다.
