# 도시뉴스 AI 브리핑

> 상태: 운영 중 · 시작: 2026-06-30 · 관련 레포: API, Front

도시공학·도시계획 뉴스를 매일 모아 LLM 1회 호출로 구조화된 브리핑을 발행하는 기능(도시뉴스 탭).

- [backend.md](backend.md): 수집·요약 파이프라인, 응답 스키마, LLM 호출 설계 (원래 `Mapshot-API:docs/news-ai-digest-feature.md`)
- [frontend.md](frontend.md): 브리핑 읽기 화면, 렌더링 규칙 (원래 `Mapshot-API:docs/frontend-news-digest.md`)

## 알려진 문제 (2026-11-25 점검)

브리핑 목록과 11/24 브리핑 한 편을 직접 읽고 찾은 것. 품질 평가(eval)를 붙일 때 기준점으로 쓴다.

- 도시 분야와 무관한 기사가 섞인다. 키워드(`도시재생` 등) 검색 결과를 날짜순으로 5건씩만 받고 관련성 필터가 없어서다.
  예: '스마트시티' 섹션에 식품분석평가 기사, '도시재생' 섹션에 군 예산안 기사.
- 같은 기사가 두 번 들어간다. 중복 제거가 URL 해시뿐이라 제목이 거의 같은 다른 언론사 기사는 못 거른다.
- `nextStep`("다음 일정")에 일정이 아니라 일반론이 들어간다.
- 용어 풀이에 본문에 없는 용어가 나온다.
- 도입·마무리 문장이 날마다 거의 같다.
- LLM 실패 시 폴백(`fallbackDigest`)이 네이버 description 을 그대로 노출한다. 깨진 문자열(`}{약력/...`)이 그대로 보인 날이 있었다(10/26, 11/06).
- 입력이 네이버 API 의 제목 + 한두 문장 요약뿐이라 내용이 얕다. 언론사 본문 수집은 저작권 문제로 하지 않는다.
