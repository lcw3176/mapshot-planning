# 필지 질문: 공공데이터 연동

## 키 설정

공공데이터포털에서 아래 세 API를 각각 활용신청한다. 서버 실행 환경변수 `PUBLIC_DATA_SERVICE_KEY`에 일반 인증키를 넣는다. 포털의 인코딩 키와 디코딩 키를 모두 사용할 수 있다. 프론트 환경변수나 브라우저 코드에 넣지 않는다. 키가 없으면 기존 브이월드 필지 조회는 그대로 동작하고, 추가 데이터 질문에는 설정 안내가 표시된다.

- [건축HUB 건축물대장정보](https://www.data.go.kr/data/15134735/openapi.do): 표제부 `getBrTitleInfo`
- [토지이용규제정보서비스](https://www.data.go.kr/data/15058410/openapi.do): 행위제한 `DTarLandUseInfo`
- [토지 매매 실거래가 자료](https://www.data.go.kr/data/15126466/openapi.do): `getRTMSDataSvcLandTrade`

로컬 PowerShell 예시: `$env:PUBLIC_DATA_SERVICE_KEY = '발급받은_키'` 후 서버를 재시작한다. 실제 키는 Git에 커밋하지 않는다.

## 조회 범위와 제한

- 건축물대장은 PNU에서 시군구·법정동·산 여부·본번·부번을 분해해 표제부 첫 페이지 최대 100건을 조회한다. 부속지번, 현장 상태, 소유권은 별도로 확인해야 한다.
- 행위제한은 브이월드 토지이용계획에서 **포함** 관계인 지역지구 코드만 연결한다. 카페·음식점·공장·주택·상가 질문만 행위명으로 매핑한다. API는 시군구/지역지구의 일반 정보를 제공하며 특정 필지 인허가 결론이 아니다. 저촉·접함 지역지구는 자동 판단에서 제외한다.
- 토지 거래는 해당 시군구의 최근 완료된 3개월을 조회한다. 각 월 첫 페이지 100건에서 최대 5건만 표시한다. 일부 지번이 비공개되므로 선택한 필지의 거래 내역이나 가격 추정에 쓰지 않는다.
- API 오류 시 키·요청 URL·원문 응답을 로그나 사용자 답변에 노출하지 않는다. 키 등록 후 각 API의 실제 응답 형식과 데이터 누락률을 표본 필지로 검증해야 한다.

## 점검 질문

1. 건축물이 있는 필지에서 `현재 등록된 건물은?` → 주용도·연면적·사용승인일 및 출처.
2. 건축물이 없는 필지에서 같은 질문 → `조회 결과 없음`, 건물 부재 확정 금지.
3. 포함·접함 지역지구가 섞인 필지에서 `카페 할 수 있어?` → 포함 구역만 조회, 인허가 결론 유보.
4. `최근 토지 거래 사례는?` → 시군구 사례와 조회 기간·표본 제한 명시.
5. 키를 비운 상태에서 위 질문 → 기존 필지 질문은 동작하고 추가 API 설정 안내 표시.
# Gemini 필지 답변

서버 환경변수 `GEMINI_API_KEY`에 발급한 Gemini API 키를 설정하면, 필지 질문의 조회 근거를 `gemini-3.1-flash-lite`가 자연스러운 한국어 답변으로 설명합니다. 모델을 바꾸려면 `GEMINI_MODEL`을 설정합니다. 키는 프론트엔드에 넣지 않습니다.

서버가 질문 범위를 먼저 확인하고 기존 브이월드·공공데이터 조회 결과와 출처를 만든 뒤 Gemini에 전달합니다. Gemini는 답변 문구만 생성하며, 조회 상태·근거·추가 확인 항목은 서버가 결정합니다. 무관한 질문과 대표적인 프롬프트 인젝션 표현은 서버에서 거절합니다. 키 미설정 또는 생성 실패 시 기존 조회 답변을 표시합니다. 특정 필지의 인허가 가능 여부처럼 근거가 부족한 판단은 기존과 같이 유보합니다.

## 필지 요청 오류 추적

각 응답의 `X-Request-Id`를 서버 로그의 `request_id`로 검색합니다. 브라우저 콘솔의 `[Mapshot API]` 항목에도 요청 구간, HTTP 상태, 출처, 단계, 요청 ID가 표시됩니다. 화면의 실패 메시지에도 가능한 경우 요청 ID를 붙입니다.

- `source=server stage=cors`: 필지 요청이 서버의 CORS 검사에서 거절됨
- `source=server stage=server_filter`: 컨트롤러에 들어가기 전 403 거절. CORS 이외의 접근 설정 확인
- `source=vworld stage=parcel-by-point`: 좌표에서 PNU를 찾는 브이월드 호출 실패
- `source=vworld stage=ladfrlList` 등: PNU의 세부 속성을 가져오는 브이월드 호출 실패
- `provider=public-data stage=...`: 건축물대장, 토지이용규제 또는 거래 API 실패. `upstream_status`가 있으면 원천 API의 HTTP 상태
- `provider=gemini stage=generateContent`: 답변 문장 생성 실패. 기존 조회 답변으로 대체

브이월드 HTTP 실패는 서버에서 502로 반환하고, 응답 JSON의 `source`, `stage`, `upstreamStatus`로 구분합니다. 외부 호출 URL·인증키와 채팅 질문 본문은 로그에 남기지 않습니다.
