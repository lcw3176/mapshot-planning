# 공공 공간정보(브이월드·국토지리정보원·공공데이터포털)로 큰 위성/배경지도 이미지를 합성·배포할 수 있는가

조사일: 2026-11-25. 웹 검색과 원문 페이지 확인 기반. 원문을 직접 확인한 문서는 "원문 확인"으로, 2차 자료만 있는 것은 "2차 자료"로, 근거를 못 찾은 것은 "확인 필요"로 표시했다.

## Q1. 브이월드(VWorld) 오픈API: 약관, 레이어, 줌, 호출 제한, 저장/합성 가능 여부

### Takeaway
브이월드 오픈API 이용약관(2026-10-30 시행, 원문 확인)은 **영리 이용은 사전 승낙 없이 허용**하지만, **"데이터는 무단으로 저장하지 못합니다"(제19조 제6항)** 와 **"사전 승낙 없이 복사, 복제, 변경 … 타인에게 제공할 수 없습니다"(제19조 제4항)** 를 둔다. 따라서 서버(또는 브라우저)에서 타일을 받아 5000×5000 이미지 하나로 합성해 사용자에게 파일로 건네는 방식은 문언상 "저장·복제·변경·타인 제공"에 해당할 소지가 커서 **운영기관(공간정보산업진흥원) 사전 승낙 없이는 위험**하다. 반면 약관은 "캡처화면"에 출처를 표기하라고 규정해(제13조 제9항), 지도를 화면에 띄우고 **사용자가 캡처하는 쓰임은 약관이 전제하고 있다**.

### Inferences
- **서버 합성 후 파일 제공 = 약관상 회색지대 → 사전 승낙 필요로 보는 것이 안전.** 제20조 제3항으로 광고 수익(영리)은 문제 없지만, 타일 수십~수백 장을 받아 한 장으로 붙여(복제·변경) 사용자에게 다운로드로 넘기는(저장·타인 제공) 흐름은 제19조 제4항·제6항 문언에 정면으로 걸린다. "무단으로"·"사전 승낙 없이"라는 표현은 승낙받으면 된다는 뜻이기도 하므로, **운영기관에 서면 문의해 승낙을 받는 것이 정공법**이다(비용 0원).
- **브라우저에서 브이월드 지도를 그리고 사용자가 캡처하는 현재 방식과 비슷한 구조는 약관이 상정한 사용.** 제13조 제9항이 "캡처화면"에 출처 표기를 요구하므로, 캡처 자체는 허용을 전제로 한다. 따라서 "브라우저에서 브이월드 WMTS로 큰 캔버스를 렌더 → 출처 문구('브이월드' 등 운영기관이 정한 방식)를 이미지에 그려 넣음 → 사용자 자신이 저장"은 현재 카카오 SDK+확장 캡처보다 약관상 훨씬 나은 위치다. 다만 서비스가 '원클릭 다운로드 버튼'으로 파일을 만들어 주면 서비스가 복제·제공 주체가 되므로 위의 승낙 문제가 다시 생긴다. 이 경계는 해석 문제라 확인 필요.
- **현재 도시계획 레이어 Lambda 프록시도 같은 조항 영향권.** bbox로 WMS를 받아 그대로 전달만 한다면 "표출"에 가깝지만, Lambda/CDN에서 캐시하면 "저장"으로 볼 여지가 있다. 승낙 문의 시 함께 묻는 것이 좋다. 또한 WMS는 HTTPS/비웹뷰어 호출 시 `domain` 파라미터와 키-도메인 일치를 검사하므로 서버 프록시 호출이 정책상 허용되는 형태인지도 함께 확인 필요.
- **해상도·크기 면에서는 충분.** 위성 줌 19까지 제공되므로 반경 10km(지름 20km)를 5000px에 담는 데(약 4m/px, 대략 줌 15 수준) 해상도 문제는 없다. StaticMap은 1024px 상한이라 대형 이미지는 WMTS 타일 합성이 필요하다.

### Gaps
- 키당 일일 호출 한도 수치(WMTS/WMS/StaticMap별): 약관은 "별도로 공지"라고만 하고 가이드 페이지에도 숫자가 없다. 개발자센터 공지/마이페이지에서 확인 필요.
- 제13조 제9항의 "운영기관이 별도로 정하는 방법"(출처 표기 문구·위치) 원문: 확인 필요.
- 브이월드 위성(Satellite) 타일의 원천(국토지리정보원 항공 정사영상인지)과 갱신 주기·촬영 연도: 공식 문서에서 확인 못함 — 확인 필요.
- 운영기관이 "타일 합성 이미지 다운로드 제공"을 승낙한 선례 여부: 공개 자료 없음.

## Q2. 국토지리정보원(NGII) 국토정보플랫폼: 정사영상·항공사진 다운로드 조건

### Takeaway
국토지리정보원은 정사영상(도시 12cm, 일반 25cm, TIFF, 2010년 이후)을 국토정보플랫폼에서 무료로 내려받게 하지만, **라이선스 표시가 데이터셋마다 서로 다르다**(정사영상: "제한 없음" / 국토영상정보(항공사진): 공공누리 **제3유형 출처표시·변경금지**). 원본을 받아 잘라 붙여 사용자에게 재배포하는 서비스는 3유형의 "변경금지"와 보안 분류기준(좌표 포함 고해상도 = 공개제한, 인터넷 좌표 표시 불가)에 동시에 걸릴 수 있어 **사전 확인 없이는 쓰기 어렵다**. 전국 TIFF를 받아 직접 타일 서버를 운영하는 것은 저장·대역폭 비용도 커서 1인 무료 티어 운영에 맞지 않는다.

## Q3. 공공데이터포털·공공누리 유형과 상업적 재배포·변형

### Takeaway
공공누리 1유형만 "상업 이용 + 변형" 둘 다 허용한다. 광고 수익 서비스가 영상을 합성해 배포하려면 **1유형(또는 '제한 없음')이 명확한 자료**여야 하는데, 정사영상 계열은 표시가 엇갈리고 브이월드 API 데이터는 공공누리가 아니라 **별도 이용약관**(저장·복제 제한)이 우선 적용된다.

### Cited Findings
- 공공누리 1~4유형 조건(1: 출처표시 / 2: +상업금지 / 3: +변경금지 / 4: +상업·변경금지). — [브이월드 저작권정책](https://www.vworld.kr/v4po_prcint_a006.do); [공공누리](https://www.kogl.or.kr/info/license.do)
- 1유형 출처표시는 발행연도, 공공기관명, 홈페이지 URL 등을 포함해야 함. — [공공누리 이용안내](https://www.kogl.or.kr/info/publicGuide.do)
- 브이월드 약관 제19조 제6항 단서: 다운로드 서비스에서 "개별 라이선스가 표시된 자료는 해당 라이선스에 따릅니다" — 즉 API 타일은 약관, 다운로드 파일은 개별 라이선스. — [브이월드 이용약관](https://www.vworld.kr/v4po_prcint_a001.do)
- 공공데이터포털 API 항목은 "이용허락범위 제한 없음"으로 표시되지만 실제 이용은 제공기관(브이월드) 약관을 따름. — [data.go.kr 15140371](https://www.data.go.kr/en/data/15140371/openapi.do)

### Inferences
- 공공데이터법상 공공데이터는 영리 목적 포함 자유 이용이 원칙이라고 브이월드 저작권정책도 언급하지만, 실제 서비스 채널(API)의 약관이 저장·복제를 제한하므로, 맵샷이 "공공데이터니까 마음대로 합성해도 된다"고 주장하기는 어렵다. 포털 표시('제한 없음')와 약관의 충돌은 문의 시 근거로 활용할 수 있다.

### Gaps

## Q4. 보안 규제: 보안시설 가림, 해상도·좌표 제한

### Takeaway
law.go.kr에 게시된 "국가공간정보 세부 분류기준"(별지 제1호 서식, 파일 생성 2026-01-07)에 따르면 항공사진은 **2차원 좌표가 포함된 30m보다 정밀한 자료가 '공개제한'**, 공개 등급 자료도 **"인터넷, 네비게이션, 휴대폰에는 좌표 표시 불가"**, **25cm보다 정밀한 항공사진은 관리기관 승인 시에만 제공·판매**다. 공개된 정사영상을 써도 **좌표(지오레퍼런스)를 붙여 온라인으로 배포하는 형태**는 규제 쟁점이 된다. 브이월드 약관도 이 규정 위반을 이용제한 사유로 명시한다.

### 종합 판단(조사자 의견, 보고서 작성자 참고)
1. 원클릭 대형 이미지를 **합법적으로 서버 합성·배포**할 공공 소스는 현재 약관만으로는 확인되지 않는다. 가장 현실적인 길은 **브이월드 운영기관(공간정보산업진흥원)에 서면으로 "WMTS 타일을 합성해 출처 표기를 넣은 단일 이미지로 사용자에게 제공(무료, 광고 수익)"에 대한 사전 승낙을 받는 것**. 약관 문언이 "무단으로/사전 승낙 없이"라 승낙 경로는 열려 있고, 비용도 들지 않는다.
2. 승낙 전 대안: 브라우저에서 브이월드 WMTS로 큰 캔버스를 렌더링하고 출처를 표기한 뒤 사용자가 저장하게 하는 방식은 제13조 제9항(캡처화면 출처 표기)과 가장 가깝다. 단, 이것이 "서비스가 복제물을 제공"으로 보일지는 해석 문제라 승낙 문의에 같이 포함할 것.
3. NGII 원본 정사영상 직접 서빙은 라이선스 표시 충돌(제한없음 vs 3유형 변경금지), 좌표·보안 조항, 인프라 비용 때문에 우선순위가 낮다.
4. 어느 경로든 산출물에 **좌표(GeoTIFF/월드파일)를 넣지 말 것**, **출처 표기를 이미지 안에 굽기**를 기본값으로 둘 것.
