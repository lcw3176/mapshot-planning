# 지역 추출 평가

LLM 이 보도자료에서 뽑은 지역이 맞는지 재는 곳. 요약 품질과 달리 정답이 분명해서(어느 시군구냐) LLM 심판 없이 정밀도·재현율로 바로 잴 수 있다.

## 정답셋

- [region-gold-2026-11-25.json](region-gold-2026-11-25.json): 2026-11-16~25 국토부 보도자료 30건. 제목·부제만 보고 손으로 단 정답.
  - 키는 국토부 게시글 id(`press_release.external_id`). 파일에 없는 id 는 NATIONAL(지역 없음)이 정답.
  - 30건 중 LOCAL 6건, NATIONAL 24건.
- 애매했던 것
  - `95092620` 부전마산 복선전철 낙동1터널: 노선 이름의 '부전'(부산), '마산'(창원)을 지역으로 봤다. 사고 지점의 정확한 시군구는 제목·부제에 없다.
  - `95092622` "강원권에 이어 무주·진안·장수": '강원권'은 권역 표현이라 뺐다.
  - `95092602` "호남권 반도체 국가산단": 권역 표현이라 NATIONAL.
  - `95092634` 스마트건설 엑스포 "고양시 킨텍스": 행사 장소도 LOCAL 로 봤다(프롬프트 기준 '현장 방문지·장소').

## 재는 방법(계획)

1. 운영 DB 의 `press_release` 에서 정답셋 id 들의 `scope`, `region_codes` 를 뽑는다.
2. 정답 지명을 `RegionDictionary` 로 코드로 바꾼다(코드 기준 비교).
3. 건 단위로 본다.
   - scope 정확도: LOCAL/NATIONAL 맞힌 비율
   - 지역 정밀도: 찍은 코드 중 정답에 있는 비율
   - 지역 재현율: 정답 코드 중 찍은 비율
4. 틀린 건은 `extraction_raw`(LLM 원문)를 보고 원인을 나눈다: 프롬프트 기준 문제 / 사전 별칭 부족 / LLM 실수.

정답셋은 운영하면서 늘린다. 프롬프트를 바꿀 때마다 같은 셋으로 다시 잰다.

## 첫 비교 거리

2026-11-25 에 입력이 '제목·부제'에서 '제목·부제·PDF 본문 앞 3,000자'로 바뀌었다. 정답셋은 제목·부제만 보고 단 것이라,
본문을 넣으면 정답에 없는 지역(본문 표의 사업 위치)을 찍을 수 있다. 처음 잴 때는 틀린 건을 '진짜 오답'과 '본문엔 있었던 지역'으로 나눠 보고,
후자는 정답셋을 고친다.
